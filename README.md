# BJA Consulting Landing Page

Landing page moderne pour BJA Consulting avec support bilingue EN/FR.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- shadcn-style components
- Framer Motion
- Lucide React

## Langues

Le site contient un sélecteur de langue EN/FR dans la navbar. Le choix est sauvegardé dans `localStorage`.

## Démarrage

```bash
yarn install
yarn dev
```

ou

```bash
npm install
npm run dev
```
